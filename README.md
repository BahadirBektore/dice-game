# 🎲 Dice Game

A simple and fun dice game built with **HTML, CSS, and JavaScript**.
Each time the page refreshes, two players roll a dice and the winner is displayed instantly.

---

## 🚀 Live Demo

👉 https://bahadirbektore.github.io/dice-game/

---

## 📌 Features

* 🎲 Random dice roll (1–6)
* 🖼️ Dynamic dice image update
* 🏆 Winner detection system
* 🤝 Draw condition support

---

## 🧠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

---

## ⚙️ How It Works

* Page loads → JavaScript runs
* `Math.random()` generates numbers between 1–6
* Dice images update dynamically
* Scores are compared
* Winner is displayed on screen

---

## 🎮 Game Rules

* Two players roll automatically
* Higher number wins
* Same number = Draw
